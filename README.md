# PDF-conversion-and-merging
 
This is a small Python script I made to convert Word and Excel files into PDF files and then merge all PDFs into one file.
 
I needed this because sometimes assignments are spread across multiple documents and I wanted to submit everything as a single PDF.
 
## What it does
 
The script can:
 
- Convert Word (.docx) files to PDF
- Convert Excel (.xlsx) files to PDF
- Automatically set Excel sheets to landscape mode
- Resize Excel sheets to fit on one page
- Merge all generated PDFs into one PDF file
